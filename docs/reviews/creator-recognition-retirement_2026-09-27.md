# 旧达人识别机制退役

## 范围

删除全员身份扫描、独立负责人推断、人员反向 handle 扫描、旧三阶段流程，以及旧候选确认和分类修改入口。同步删除专属页面、资源、提示词、执行代码和测试；Worker 和共享 AI 限流仅保留 CAP、摘要、回复建议任务。

CAP 的授权校验、脱敏、handle 规范化及证据指纹函数保留到三个共用取证模块。CAP 模型配置独立为 `creator_import`；迁移复制已有加密凭证，不输出密钥，不自动启动批次。密文域不变，历史 CAP 证据仍可解密。

旧后台路径为 404；旧 handle 操作保留受登录/CSRF 保护的 410。旧证据页面不再读取正文。人员目录保留历史已验证分类，不再显示旧扫描进度。原始消息、授权、已确认关系、CAP 批次和历史证据不删除；旧表及外键暂存，不重放早期清库迁移。

全量英国 handle 识别不属于本次发布。
