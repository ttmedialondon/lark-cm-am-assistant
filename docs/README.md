2026-10-04 新增群用途分类：客服、机构达人、培训、类目、活动及未确认。共享群只分析一次，AI 建议经 Owner 确认后才成为正式分类；不自动群发。完整规则与 120 位达人相关群的研究范围见下表。

2026-09-14 的达人清空、CAP 名单和关闭 AI 记录是历史操作，不代表当前功能状态；恢复与清理边界见对应历史文档。

## 后续怎么维护

1. 同一条业务规则只改对应的那一份业务文档；技术文档说明实现，不再复制整份需求。
2. 新决定先写清“已确定、待确定、已实现”的区别。产品规则与代码不一致时标出差异，不自行按旧实现覆盖新决定。
3. 时段、人数、AI 开关和测试结果必须带日期；运行值以当前配置为准，历史快照不能当实时数据。
4. 旧版本从 Git 历史恢复，不再新增 `v0.x` 副本。导出的 PDF/Word 只用于分享，不另立规则来源。
5. 周报、复查、发布记录只追溯当时发生了什么；其中未来计划不自动转为开发任务。
