## 本周核心成果

### 1. 完成产品需求重新梳理

完成 Lark CM/AM 夜间消息管理与知识沉淀助手 PRD v2.0，并对旧需求进行了系统性重构。

本次明确了四条产品主线：

1. 在 CM/AM 下班期间，即每日 18:30 至次日 10:00，收集授权范围内的群聊消息。
2. 将需要次日跟进的内容整理成事件，并按 P0—P3 展示紧急程度。
3. 在员工明确授权后，持续沉淀历史沟通语料，为后续知识库做准备。
4. 接入 OpenAI 或 DeepSeek，先提供内部回复建议，暂不自动发送给客户。

同时明确建设两个核心界面：

- 夜间事件工作台：回答“今天应该先处理什么”。
- 数据沉淀看板：回答“数据同步和知识准备进展如何”。

本次 PRD 还补充了：

- 用户角色和权限边界。
- 群聊、历史消息和时间窗口口径。
- 事件状态与紧急程度规则。
- AI 使用边界和人工确认要求。
- 数据删除、撤销授权和审计要求。
- FR-001 至 FR-009 的功能需求。
- 验收标准、核心指标和分阶段交付计划。

**带来的价值：** 产品方向从“泛 AI 客服”收敛为一个可交付、可验收且风险边界明确的内部业务工具。

### 2. 完成配套技术设计

对照新版 PRD，完成技术设计文档 v2.0 实施版。

确定的核心技术路线：

- 后端继续使用 Python + FastAPI。
- 数据库继续使用 PostgreSQL。
- 新增 SQLAlchemy 2 和 Alembic，管理后续复杂数据模型与迁移。
- 前端选择 React + TypeScript + Vite。
- 界面使用 shadcn/ui + Tailwind CSS，保持干净、克制和可扩展。
- 权限采用“RBAC + 数据范围”，同时控制用户能做什么以及能看哪些客户、项目和群。
- 后台任务继续使用 PostgreSQL 任务队列和独立 Worker，暂不增加 Redis、Celery 或复杂微服务。
- OpenAI 与 DeepSeek 通过统一适配层接入，避免业务代码绑定单一供应商。

技术文档已经覆盖：

- 总体架构与代码目录。
- 身份、角色和权限。
- 公司级消息去重。
- 夜间窗口和英国夏令时。
- 事件聚合与 P0—P3。
- AI 结构化输出、安全和降级。
- API 和前端页面规划。
- 数据加密、审计和删除传播。
- 测试、监控、备份、部署与回滚。
- 从当前原型渐进迁移到正式系统的实施步骤。

**带来的价值：** 后续开发不需要边写边重新决定框架，可以围绕同一架构逐步增加页面、角色和 AI 能力。

### 4. 完成欧洲服务器选型与成本预算

对欧洲可用云服务进行了专项调研，重点比较：

- Hetzner。
- OVHcloud。
- Scaleway。

已经形成：

- 开发环境、首次上线、扩容和高可用阶段的配置建议。
- 月费与年费预算。
- CPU、内存、磁盘、IPv4、备份和流量的统一比较。
- EU 数据区域、备份和灾难恢复边界。
- 服务器扩容触发条件。

当前首选方案：

- **Hetzner CPX22。**
- 2 vCPU、4 GB 内存、80 GB NVMe。
- 服务器、IPv4 和官方备份预计约 €23.89/月、€286.66/年，税前。
- 公司内部建议按 €30—45/月、€360—540/年准备完整基础设施预算。

项目当前保持单机起步，不提前购买 Kubernetes 或复杂高可用架构；等真实用户量和性能数据出现后再扩容。

**带来的价值：** 在保证欧洲部署和基础备份的前提下，把第一版年度服务器预算控制在较低水平。

## 本周完成的关键决策

### 产品方向

从泛化的 AI 客服机器人，收敛为：

> 夜间消息收集、次日事件交接、授权历史语料沉淀、内部 AI 回复建议和双看板。

### 技术方向

确定：

> Python/FastAPI 后端 + React/Vite 前端 + PostgreSQL + 独立 Worker。

### 架构方向

确定：

> 模块化单体优先，不在第一版引入微服务、Kubernetes 和复杂中间件。

### 基础设施方向

确定：

> 欧洲 Hetzner 单机起步，CPX22 作为首次生产首选，根据真实监控数据扩容。

### 权限方向

确定：

> 角色权限控制操作，数据范围控制可见客户、项目和群；管理员默认不拥有消息正文权限。

### AI 方向

确定：

> AI 只提供内部建议，不自动外发；OpenAI 和 DeepSeek 可替换，并受授权、数据地域和供应商审批控制。

### 公司资产方向

确定：

> 域名、邮箱、GitHub、服务器、AI API 和代码均使用公司账号管理，不依赖个人资产。
