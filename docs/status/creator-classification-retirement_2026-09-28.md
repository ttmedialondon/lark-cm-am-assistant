# 达人分类机制退役 · 2026-09-28

系统统一使用“达人”，不再区分 CAP、非 CAP 或待定类型。

- 人员/达人列表与下班后事项处理依据已确认的达人身份和有效负责人关系，不再按旧类型筛选。
- 导入接口、列表响应、页面和模型提示词不再传递或展示旧类型；历史模型输入中的分类元数据不再发送。
- 入库不再设置人员类型，也不再因旧类型阻止账号匹配或复用已确认身份。
- 仍检查访问授权、商家/内部员工等身份冲突、已拒绝身份、账号归属冲突；不新增或改变负责人规则。
- 历史字段、历史迁移及审计记录保留，不清空已有身份、handle 或负责人关系。旧字段不再参与业务判断；已有上传按原文件和负责人复用，不因旧分类重复创建批次。
- 本次不启动识别任务、不启用 AI 功能、不调用外部模型，也不放宽此前研究入库的 Curva 范围。

回归验证覆盖旧类型不影响显示、匹配与提醒，且身份拒绝/撤销授权仍能停止处理。

本地隔离 PostgreSQL 全套测试：376 项通过，无跳过。上线前只读核对：没有等待/运行中的名单匹配任务；旧类型为 CAP 且已分配的人员中，缺少已确认达人身份的人数为 0（人员级、账号级关系均检查）。
