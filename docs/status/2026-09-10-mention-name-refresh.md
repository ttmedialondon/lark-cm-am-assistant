## 实现与刷新

共用 `message_mentions` 解析正文和富文本；未知或冲突的提及不猜测。支持中文紧贴 @；URL、代码、邮件中的同样字符保留原文。当前事件总结得到同一份解析正文和匿名角色映射，只有输入变化的会话重新排队。

`backfill_identity_names.py --apply --owner-id OWNER_UUID --refresh-members` 使用已有 API 限流，最多两路并行。请求前后检查授权、scope、群可见性、同步开关和代次；并发事务冲突最多重试三次，单群失败计入结果，不扩大权限。默认 dry-run 不访问 Lark 或写数据。
