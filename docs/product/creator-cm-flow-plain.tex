\blocktitle{02}{拿 Remi 举个例子}
\begin{itemize}
  \item \textbf{Excel 资料全了：} \texttt{@abc}、Remi 和对应 Lark 用户都已确认，没有冲突，才直接入库。
  \item \textbf{AI 猜到的：} \texttt{@xyz} 可能归 Remi，先放到“待确认”。Remi 看过再确认；推荐的人不对，就换一个用户。
  \item \textbf{还有信息没齐：} 就算确定归 Remi，只要缺 handle、缺 Lark 用户，或者不知道选谁，都继续待确认，不能先入库。
\end{itemize}
{\small\color{muted}上面的 handle 仅作说明，不是真实匹配结果。}\par
