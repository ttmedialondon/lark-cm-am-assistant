# 人员身份与我的达人

更新：2026-10-09。本文是当前规则；历史 CAP 名单及三阶段扫描记录不代表现行功能。

## 1. 人员、账号与负责人

- 人员身份、TikTok handle、CM/AM 负责人、群用途分别管理，不互相推导或覆盖。CAP/非 CAP 已取消。
- 达人按联系人 ID 去重，不按姓名合并；同一人可有多个 handle、多个负责人。同一账号涉及其他人的正式关系时保留冲突，不自动转移账号或合并人员。
- 负责人候选仅为“人员”页面已接入且有效的 CM/AM。识别或上传操作本身不产生负责人；有效名单、人工确认，或通过当前负责人匹配规则的结果，才建立正式关系。
- 人工确认和人工导入数据保留。新表缺少旧账号，不删除原关系。
- 普通 CM 使用本人范围；Owner 或获准的达人管理人员可跨 CM 管理。关联达人不增加聊天读取权限。

## 2. 当前入口

“我的达人”默认显示正式名单；Owner 可切换“未分配达人”，不再有独立候选达人页面。姓名进入有权限的个人资料，旁边的小图标打开 Lark 私聊，不发送消息。

名单按人展示全部已关联账号，可按维护优先级排序、筛选。优先级分为重点、优先、常规、久未联系、待评估；基于本人授权聊天，不依赖 Curva 或 GMV，并随新资料和时间变化。Owner 可手动调整优先级、修改账号；人工调整优先，不展示冗长分析依据。

## 3. 名单导入

选择负责人 → 上传单列 handle Excel → 检查预览 → 确认导入 → 后台找群、找人 → 满足证据及配置阈值则入库，其余人工核对。

每行一个账号，去重后独立处理；上传者与所选负责人分别记录。导入机制不再要求 CAP 或 Curva 收录，不创建空壳联系人。多群成员按稳定联系人合并；相似群名、同名人员、共享群不能单独证明账号归属。只有完整成员与对应群证据支持唯一人选时，才可判断没有发言的成员。

取材限于所选 CM 当前可读范围。找群、找人保留完整问答、引用、覆盖缺口和实际用量；找群结论不成立时，不继续付费猜人。人工核对入口保留在导入批次内，不恢复旧候选队列。

## 4. 已确认达人的自动匹配

- **Handle 匹配**：从群名、本人发言、完整问答和账号链接召回候选，再核对本人关系。Curva 只是辅助目录；未收录不否决明确账号。默认跳过同一人已正式关联的账号，但仍寻找其新账号；主动复核或实际冲突时才重查旧关系。规则见 [账号协议](../specs/creator-handle-association-prompt_v1.2.md) 与 [队列方案](../specs/creator-handle-matching-queue-plan_v1.0.md)。
- **负责人匹配**：依据已接入 CM/AM 与达人的真实业务互动，不仅凭“在同一个群”。符合配置阈值和证据要求时自动新增关系；可保留多位负责人，不覆盖人工归属。规则见 [负责人匹配](../specs/creator-responsibility-matching_v1.0.md)。
- **群用途分类**：客服、机构达人、培训、类目、活动；不足时未确认。共享群只处理一次，达标自动入库，人工分类优先；详情显示分类角标。规则见 [群分类](../specs/creator-group-classification-prompt_v1.1.md)。
- **维护优先级**：模型提取聊天事实，后端结合近期互动和时间分档；每位 CM 的依据独立，不因共用达人而共享聊天。规则见 [事实提取协议](../specs/creator-importance-facts-prompt_v1.0.md)。

各功能独立配置和持久化队列，当前由共享 AI 并发准入公平调度；桌面主动请求和群发发送队列独立。开关以线上为准，代码发布不自动开启、重扫或改变阈值。

相同材料复用结果；授权、正文、群名、身份或配置变化使受影响材料失效。明确可重试的失败有限重试；请求结果未知保留回执，等待人工核实，不自动重复付费。正式写入前核对当前授权、引用、版本及冲突。

## 5. 下游与退役边界

正式确认身份或新增有效负责人关系，会登记最近七个英国日期的消息总结补算信号；需功能已启用、已有负责人且消息当前可读。已有账号或群分类不是总结前提。规则见 [消息总结](message-summary.md)。

群分类用于群发选择，不直接触发发送；客服群按人匹配，其他类别按本人可见群选择。名单、模板、确认和回执规则见 [部署手册](../runbooks/deploy-mvp.md#群发页面与正式发送)。

旧联系人泛扫身份、旧负责人扫描、从人员反查 handle 及“身份 → 负责人 → handle”流程已退役；旧入口不能执行或确认。历史任务、密文域、来源引用和正式关系保留，供现行读取、审计及冲突核对，不重放历史清理迁移。
