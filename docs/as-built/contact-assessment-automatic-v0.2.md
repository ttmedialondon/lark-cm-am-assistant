# 联系人自动识别（当前实现）

状态：**已部署。** 本文是联系人 AI 角色识别的当前运行契约。

## 目标

在 CM/AM 已授权、且消息正文仍处于可读取范围内的前提下，自动为尚未确定身份的外部联系人生成**主类别**判断。系统不会发送 Lark 消息，也不会把模型建议用于自动回复。

## 何时入队

启用功能后，worker 每分钟最多一次把全部符合条件的联系人写入 PostgreSQL 的 `contact_assessments` 队列。该队列是持久化的：服务重启不会丢失待处理联系人，也不会因为还有旧任务而停止发现新联系人。

同一时刻全局只运行 1 个自动识别任务，数据库还保证两次自动调用至少相隔 3 秒。正常情况下同步优先；若首次回填持续产生同步任务，worker 最多连续完成 3 个同步任务后会给自动识别队列一次机会，避免长期饿死。

联系人首次满足以下条件时，只要有 **1 条** 有效消息正文即可入队：

- 是非内部 Lark 用户身份（已知外部或尚未归类）；
- 有活动授权、正文同步同意、可见且开启同步的会话；
- 该消息尚未撤回，且正文仍可解密；
- 联系人没有运行中或排队中的同类任务；
- 联系人没有已确认角色。

“已确定”是硬规则：任一 `contact_roles.status = confirmed` 都会阻止入队。任务真正调用 OpenAI 前和写入结果前会再次检查，因此即使旧任务已排队，也不会为已确定联系人产生新的模型调用。

消息观察使用不可变的首次发现时间作水位；普通的重叠增量同步不会重复触发评估。自动任务的后续策略是：

- 自动确认或待人工处理的结果不会自动重跑；
- 无可执行建议的**成功结果**，只有新增至少 5 条仍在授权范围内的该联系人消息后才会再试；
- 临时失败、无效模型结果或 worker 中断只会影响该联系人：同一水位最多自动重试 3 次，每次至少间隔 15 分钟；达到上限后需有新消息才会形成新的重试水位，避免异常时持续消耗额度；
- 单条模型格式、网络或限流失败绝不会暂停其他联系人的自动识别。

“待识别”不是业务类别；模型只有在正向证据支持时才可建议“其他已确认外部联系人”。

## 证据包与模型调用

每次调用只构造当前仍可读取的最小证据包：命中消息、同一会话前后各最多 6 条、联系人最多 4 条近期发言，以及会话类型/租户属性。包固定包含 `TT Media London`，并且只带该联系人的已验证 Lark 关联组织；不会带整群成员名单、其他人的组织或未经核验的组织候选。群名只随命中消息发送一次，作为弱证据，不能单独确认身份。上限为 17 个消息片段、约 8,000 个正文字符；已有确认身份的联系人不会调用模型。

调用使用 OpenAI Responses API、`gpt-5.6-luna`、`store: false`、严格 JSON Schema。服务端保存经过校验的角色建议、用量和消息引用，不保存 prompt 或模型自由文本。角色建议必须引用实际输入的 `M1` 等消息编号；角色编号或结构不合法时整次结果作废。

在把正文发送给模型前，以及模型返回后写入前，都会重新检查引用消息的授权、会话可见性和撤回状态。授权范围变化时任务取消，不写入业务事实。

## 决策与人工处理

管理员在 `/admin/ai` 配置自动确认阈值，默认且最低为 **90%**（可设为 90%–100%）。

- 仅有一个业务类别达到阈值、证据可核验、不存在其他高置信类别冲突，且引用中存在 P2P / 回复 / @ 的直接关系或联系人本人自述时，才会以 `ai_auto_confirmed` 写入主类别；
- 低于阈值或与既有事实冲突的可确认建议，保留在对应外部联系人的详情中；
- 没有可执行建议（例如模型仅返回信息不足）不会伪造候选或事实；
- 管理员从外部联系人详情打开受当前授权保护的引用证据，逐项人工确认，或不采纳本次建议。

自动确认和人工确认均写入审计日志。页面查看正文、确认和候选处理不记录消息正文到审计日志。

已确认主类别会在 `/admin/contacts` 和联系人详情的姓名旁展示。类别固定为：达人 / 内容创作者、合作机构对接人、TT Media London 同事、商家 / 品牌方对接人、字节系平台官方对接人、其他已确认外部联系人。内部同事只由内部 Lark 租户事实写入，不会调用模型；候选、低置信建议和未确认结果保持“待识别”。

## 边界

- `creator` 必须由可核验的消息证据和阈值共同支持；不从昵称、头像、普通 `@` 提及、群成员人数、群名或单一消息片段直接确认类别。
- 不评估已确定联系人；如业务事实需要变更，应先由管理员按业务流程修正联系人事实，再决定是否重新评估。
- 不对 Lark 发送消息，不创建机器人回复，不跨越授权可见范围读取正文。
