# 达人维护判定边界与案例

## 使用说明

以下案例整理自现有维护优先级协议的规则示例，不是本次重新阅读生产聊天得到的新结论，也不是准确率测试。用于校准业务事实，不让模型直接输出档位；最终档位仍由现有程序计算。

表中“常规”默认资料有效、近期有相关消息，且近 30 个英国日期的有效双边业务交流不足 3 天；达到 3 天可为优先，不因频率成为重点。近期有效主要事项对应近 7 天重点、超过 7 天但仍在近 30 天内优先；其他条件、人工档位和来源校验不变。

## 机会、权益与交付

| 证据场景 | 应提取的事实与边界 |
| --- | --- |
| CM：“愿意做 Acme 视频吗？”达人：“可以了解一下。” | 只是意向，未证明双方具体商谈可推进方案。不能为凑机会把泛泛兴趣改成已成立。 |
| CM 提出 Acme 视频的报价／档期，达人讨论产品并要求继续推进 | 有双方在谈的具体机会；待最终批准并不自动否定已经明确的新交付方案。 |
| 达人询问闪购，CM 后续明确当地不支持，只能申请平台补贴；双方继续核对资格及既有直播 | 已否定的闪购不是活跃机会；平台操作只按有效双边交流记录，不由预估 GMV 推断价值。 |
| 达人询问“DJI 全部产品能有直播专属价吗”，CM 激活价格或链接 | 权益／价格支持，没有本人交付承诺，不是持续合作。 |
| CM：“Roborock 每天安排闪购。”达人：“今晚我会播，先看看效果。” | 每天修饰价格安排，今晚是本人独立计划；未证明双方新的交付约定，保留业务交流或意向。 |
| CM：“今晚请安排一场 Roborock 产品直播。”达人：“确认，今晚播这款。” | 双方具体单场交付可为 `agreed`；同场有价格支持不应否决真实安排，也不能升级为周期合作。 |
| CM 对某条已发布视频提出投流、索取 ad code，达人确认并给码 | 新投流机会，引用索码与回复；原视频发布和给码均不等于本轮投流完成。 |
| 双方核对已寄样产品的地址和物流，没有新内容提案 | `interaction`，按有效原文日期去重；重复十条消息不是十次业务日期。 |

## 成立、完成与重复合作

| 证据场景 | 应提取的事实与边界 |
| --- | --- |
| CM：“Acme 面霜安排一条视频，周五发布可以吗？”达人：“确认，周五发这条。” | 双方成立单次合作，不能因为没有付费条款就否决实际交付。 |
| CM：“每周固定播 Acme 可以吗？”私聊一分钟后达人：“Yes, agreed.” | 完整问答可支持周期交付，引用双方且仍须符合实际上下文；群内不明对象的 Yes 不能照搬。 |
| 已约定“三条视频、总价 £100、指定日期前交付”，本人随后确认三条全部完成并发链接 | `agreed` 与 `completed` 使用同一个对象；完成优先引用直接完成确认和必要成立依据，不把“已完成”另起新对象。 |
| 已有同一合作成立依据，达人：“样品收到，我下周会拍。” | 不是完成；单纯寄样不新建合作机会，是否有实质推进须结合既有交付安排判断。不能凭收样关闭合作。 |
| 已有同一合作，达人：“视频已经发布，这是链接。”旁边还有多个广告码 | 本人明确发布可支持完成；链接和码不是独立完成见证，不能挤掉本人确认。 |
| 已完成后，双方核对链接、付款资料、发票或效果表 | 不重开同一合作的 `progress/opportunity`；事实已完成不因后续文书往来变成在执行。 |
| 完成后双方另行明确下一轮产品、时间和具体交付 | 新一轮可重新成立；引用本轮新约定，不能把反复讨论第一次合作当成复购。 |
| “我朋友昨天直播卖得很好” | 不能作为目标达人的完成或商业能力证据。 |

## 不抬档、不误删

| 证据场景 | 应提取的事实与边界 |
| --- | --- |
| 群名“Acme VIP”、单方十条广播、赞美或问候 | 不证明合作成立、完成或有效业务频率；不能用群名替代消息引用。 |
| 接受机构管理、加入 WhatsApp 更新群或续期管理关系 | 沟通／管理关系，不是周期内容交付；不能因此判 `ongoing`。 |
| 纯催款、投诉或退出机构，没有新的具体合作动作 | 不新建维护机会或业务交流日期；可能需要独立事件流程处理，但不是维护档位的加分项。普通报价、费用和预算商谈不能只因含 payment／fee 就被排除。 |
| 只明确取消 Acme 秋季直播，另一品牌合作仍有效 | 只对该对象记录取消，保留其他合作。不能取消整个人的所有合作。 |
| 无新消息、附件看不懂或本批缺少问答 | 是材料缺口，不是 `cancelled/uncertain`，不删除已有有效事实，不伪造推进日期。 |
| 已知最近相关消息超过 30 天，画像来源仍有效，无近期主要事项或足够业务交流日期 | 程序可显示久未联系；只有“没查到”而不知道最近消息时间时，不能同样推断。 |
| 同一达人由两位 CM 负责，一方近期有合作、另一方资料不足 | 各自独立判断，不借另一位 CM 的事实替本人的档位抬升，也不因资料不足删除负责关系。 |

每次只提取可靠的新事实，沿用输入已有对象与状态。例子没有覆盖的表达回到完整语义和真实问答判断，不要求出现某个固定英文关键词，也不以低质量事实填满数量上限。
